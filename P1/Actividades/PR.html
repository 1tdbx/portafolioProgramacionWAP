Máquina objetivo

SNAKEOIL

Objetivo

Realizar una auditoría de seguridad sobre la máquina vulnerable SNAKEOIL dentro de un entorno controlado y aislado, identificando servicios expuestos, rutas accesibles, vulnerabilidades de la aplicación web y mecanismos que permitan demostrar el impacto de una explotación.

La actividad tuvo como finalidad aplicar técnicas de reconocimiento, enumeración, explotación y escalada de privilegios dentro de un laboratorio de seguridad informática.

Proceso realizado

01 // Reconocimiento

Identificación del host objetivo dentro de la red Host-Only mediante Nmap.

02 // Enumeración

Identificación de servicios, versiones y rutas accesibles de la aplicación web mediante Nmap, Curl y Gobuster.

03 // Análisis

Identificación de exposición de usuarios, mecanismos de autenticación y comportamiento vulnerable de los endpoints de la aplicación.

04 // Acceso

Obtención de un JWT mediante una cuenta de laboratorio y acceso al endpoint protegido /secret.

05 // Explotación

Confirmación de SSRF y ejecución remota de comandos mediante el endpoint /run.

06 // Escalada

Obtención de una sesión como Patrick y posterior escalada de privilegios hasta root.

Resultados y análisis

La auditoría permitió demostrar el compromiso completo de la máquina SNAKEOIL dentro del entorno controlado del laboratorio.

SSRF

Se confirmó que el servidor podía realizar solicitudes hacia un sistema controlado por el atacante.

RCE

Se comprobó la ejecución remota de comandos mediante el comportamiento vulnerable del endpoint /run.

Acceso inicial

Se obtuvo una sesión interactiva en la máquina objetivo como el usuario Patrick.

Root

Finalmente se consiguió acceso con privilegios administrativos sobre la máquina.

Conclusiones

La práctica permitió comprobar cómo la combinación de diferentes vulnerabilidades puede conducir al compromiso completo de un sistema.

La exposición de información sensible, la validación insuficiente de entradas, la ejecución remota de comandos y la gestión insegura de credenciales representaron los principales factores que hicieron posible la explotación.

La actividad también permitió aplicar de manera práctica técnicas de reconocimiento, enumeración, explotación y escalada de privilegios dentro de un entorno controlado.
